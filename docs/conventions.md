**Правила команды**

**Ветки**

Формат: тип/описание-латиницей-через-дефис

* feature/ - изменения уровня
* fix/ - исправление багов
* docs/ - документация
* ci/ - настройка сборки

Примеры: feature/level-gameplay, feature/level-visuals, ci/github-actions

**Коммиты**

Язык: русский.

Заголовок: тип(область): что сделано

* до 72 символов
* глагол в прошедшем времени
* без точки в конце

Типы: feat - новое, fix - исправление, docs - документация, style - внешний вид, ci - сборка, chore - служебное.

Описание - по желанию, после пустой строки. Там же пишем Fixes #номер, чтобы закрыть Issue.

Пример: feat(level): добавлены три платформы над ямой

**Содержание коммитов**

Коммиты атомарные: один коммит - одно изменение.
Если все изменения задачи находятся в одном файле сцены, их можно закоммитить вместе.
Изменение сцены и строки о нём в changelog идут в одном коммите.
