**Геймплей и физика**

**Физические параметры**

Гравитация (Project Settings → Physics 2D): X = 0, Y = -9.81.

Массы объектов:
- Игрок (CharacterPlatformer, Rigidbody 2D): Mass = 10, Gravity Scale = 0, Linear Damping = 1
- Других объектов с Rigidbody 2D на уровне нет. Уровень (Tilemap) неподвижный, у него есть только Tilemap Collider 2D, чтобы игрок мог по нему ходить.

У игрока Gravity Scale = 0, поэтому общая гравитация на него не действует. Прыжок и падение считает скрипт PlayerCharacter: Jump_gravity = 5 при подъёме и Jump_fall_gravity = 20 при падении.

Физические материалы (Physics Material 2D): в проекте их нет, у коллайдеров игрока и уровня материал не задан.

**Препятствия, враги, бонусы**

Префабов врагов, препятствий и бонусов в проекте нет. Все префабы:
- CharacterPlatformer - игрок
- Grass - декоративная трава
- TreeBackground - декоративный фон из деревьев
- PlatformerPalette - палитра тайлов для рисования уровня
- Lever - рычаг (на уровне не стоит)

Препятствиями на уровне служат сами платформы: ямы между ними, стены, уклон и висящие в воздухе блоки, по которым нужно прыгать. Всё это нарисовано на Tilemap, а не собрано из префабов.

Опасным делает падение скрипт PlayerCharacter: если игрок упал ниже Y = -5 (Fall_pos_y), он появляется снова и теряет 25% здоровья (Fall_damage_percent).

Единственный полезный (интерактивный) префаб - Lever. Его делает интерактивным скрипт Lever: у рычага есть положения (State: Left, Right, Center) и параметр Door_value, то есть по задумке он открывает дверь. Ещё у него есть Audio Source для звука, но звуковой файл не назначен.

**UI**

Интерфейса нет: в сцене нет объекта Canvas, здоровье и другие данные на экран не выводятся.

**Параметры, которые влияют на сложность и поведение игры**

Скрипт PlayerCharacter на игроке:
- Move_max - максимальная скорость
- Move_accel, Move_deccel - как быстро игрок разгоняется и останавливается
- Jump_strength - высота прыжка
- Double_jump - есть ли двойной прыжок
- Jump_fall_gravity - как быстро игрок падает
- Jump_move_percent - насколько можно управлять в прыжке
- Can_crouch - можно ли приседать
- Max_hp - здоровье
- Fall_damage_percent - сколько здоровья теряется при падении

Скрипт FollowCamera на камере:
- Camera_speed - как быстро камера догоняет игрока
- Level_left, Level_right, Level_bottom - границы, за которые камера не заходит

Камера (Camera):
- Size - сколько уровня видно на экране

Уровень (Tilemap): расстояние между платформами и высота блоков - чем они больше, тем сложнее допрыгнуть.
