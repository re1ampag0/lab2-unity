# Структура проекта

## Сцены

В проекте три сцены:

* **PlatformerDemo** (Assets/IndieMarc/PlatformerDemo) - основная игровая сцена. В ней есть уровень, игрок, камера, деревья на фоне и трава.
* **SampleScene** (Assets/Scenes) - стандартная сцена, которая появилась при создании проекта. Почти пустая: только камера и свет.
* **URP2DSceneTemplate** (Assets/Settings/Scenes) - шаблон, из которого Unity делает новые 2D-сцены. Тоже почти пустая: камера и свет.

## Игрок

Игрок - объект **CharacterPlatformer** (тег Player).

Из каких компонентов состоит:

* Transform - положение, поворот и размер
* Sprite Renderer - картинка персонажа (Character\_0)
* Animator - анимации персонажа
* Rigidbody 2D - физика
* Capsule Collider 2D - столкновения с уровнем
* Player Character (скрипт) - движение, прыжки, здоровье
* Character Anim (скрипт) - анимации
* Character Hold Item (скрипт) - предмет в руке

Что можно настроить через Inspector:

Rigidbody 2D: масса (Mass = 10), затухание (Linear Damping = 1), гравитация (Gravity Scale = 0).

Скрипт Player Character:

|Параметр|Значение|Что меняет|
|-|-|-|
|Max\_hp|100|здоровье|
|Invulnerable|выкл.|бессмертие|
|Move\_accel|15|как быстро разгоняется|
|Move\_deccel|20|как быстро останавливается|
|Move\_max|4|максимальная скорость|
|Can\_jump|вкл.|можно ли прыгать|
|Double\_jump|вкл.|двойной прыжок|
|Jump\_strength|7|высота прыжка|
|Jump\_time\_min, Jump\_time\_max|0.25, 0.5|сколько длится прыжок|
|Jump\_gravity|5|как быстро замедляется при подъёме|
|Jump\_fall\_gravity|20|как быстро падает|
|Jump\_move\_percent|0.75|насколько можно управлять в прыжке|
|Ground\_layer|Platforms|что считается землёй|
|Can\_crouch|вкл.|можно ли приседать|
|Crouch\_coll\_percent|0.65|насколько персонаж становится ниже, когда приседает|
|Reset\_when\_fall|вкл.|если игрок упал с уровня, он появляется снова|
|Fall\_pos\_y|-5|ниже какой высоты игрок считается упавшим|
|Fall\_damage\_percent|0.25|сколько здоровья теряет при падении (25%)|

## Скрипты

* **PlayerControls** - прикреплён к Managers. Задаёт клавиши управления: A и D - ходьба, Space - прыжок, Left Shift - действие.
* **PlayerCharacter** - прикреплён к игроку. Отвечает за то, как персонаж ходит, прыгает, приседает и получает урон.
* **CharacterAnim** - прикреплён к игроку. Включает нужную анимацию персонажа: стоит, бежит, прыгает.
* **CharacterHoldItem** - прикреплён к игроку. Нужен, чтобы персонаж мог держать предмет в руке.
* **FollowCamera** - прикреплён к Main Camera. Камера двигается за игроком и не выходит за края уровня.
* **CarryItem** - в сцене не используется. По названию - предмет, который игрок может поднять и нести.
* **Lever** - в сцене не используется. По названию - рычаг, который игрок может переключить.
* **ParallaxBackground** - прикреплён к Tree1, Tree2, Tree3. Двигает деревья фона медленнее уровня, чтобы казалось, что они далеко.
* **TheAudio** - в сцене не используется. По названию - отвечает за звуки.
* **ImportPackage** - в сцене не используется. Служебный скрипт, который помогает импортировать шаблон.
